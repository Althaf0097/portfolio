## 2025-08-14 - Optimizing High-Frequency Mouse-Tracking Spotlight Interactions
**Learning:** Updating element background properties with radial-gradients on mousemove causes substantial main-thread layout recalculations and repaint costs. Additionally, calling `getBoundingClientRect()` inside mousemove listeners triggers layout thrashing by forcing the browser to calculate page dimensions on every single mouse frame.
**Action:** Always cache element dimensions inside a `useRef` initialized during `onMouseEnter` or similar events. To animate trailing spotlight or glare effects smoothly, construct an absolute-positioned overlay element and manipulate its coordinates using CSS `transform: translate3d()` via GSAP `quickTo()` helpers, which shifts the work to the GPU and prevents main-thread layout thrashing.
