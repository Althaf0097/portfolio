## 2025-02-18 - High-Performance 3D Tilt and Rendering Optimizations
**Learning:** High-frequency mouse event handlers in React that rely on `getBoundingClientRect()` inside the `onMouseMove` loop cause layout thrashing and high main-thread layout recalculation costs. Using absolute-positioned elements styled with dynamic background radial gradients also triggers heavy repaints. Animating these on elements with global `transition-all` or `transition-opacity` classes causes severe animation jitter and rendering conflicts with GSAP.
**Action:** Cache component dimensions inside a `useRef` initialized during `onMouseEnter` rather than calling `getBoundingClientRect()` inside `onMouseMove`. Use pre-initialized GSAP `quickTo` helpers for smooth GPU-accelerated transforms like `rotateX`, `rotateY`, `y`, and `scale`. Move mouse-tracking glare/spotlight effects by translating a static gradient overlay element using `transform: translate3d()` via `gsap.quickTo` to leverage hardware acceleration and eliminate layout recalculations. Remove conflicting CSS transitions on animated properties.
