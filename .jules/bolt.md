## 2025-02-18 - [Optimizing High-Frequency Interaction Elements]
**Learning:** High-frequency mouse tracking elements (like InteractiveCard or 3D scene inputs) suffer severely from layout thrashing and repaint overhead if they query element dimensions using `getBoundingClientRect()` inside mousemove listeners. Additionally, constantly creating and updating background gradients on the CPU during move events degrades framerate. By caching bounding box dimensions inside a `useRef` on mouseenter and animating glare movement on a separate hardware-accelerated absolute overlay using GSAP `quickTo` helpers via `transform: translate3d()`, we shift the load to the GPU, preventing repaint costs and rendering conflicts.
**Action:** Always cache dimensions in high-frequency mouse-tracking elements during mouseenter and leverage `gsap.quickTo` combined with GPU-friendly transforms for spotlight glare and positioning effects.
