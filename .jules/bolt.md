## 2025-02-18 - Heavy canvas and array generation on every render inside R3F components
**Learning:** Generating canvas-based textures (via dynamic `CanvasTexture`) and calculating geometric positions arrays dynamically inside React Three Fiber render loops causes severe garbage collection churn and memory leaks. In addition, using `.getBoundingClientRect()` inside high-frequency mousemove events causes main-thread layout thrashing, while global CSS transitions (like `transition-all`) cause animation conflicts and jitter with GSAP.
**Action:** Always memoize Canvas textures and arrays with `useMemo` in R3F components. Cache bounding rectangles on hover in a `useRef`, animate positions exclusively via GSAP `quickTo` helpers on static gradient overlays, and replace global transitions on animated DOM elements with specific, non-conflicting transitions.
