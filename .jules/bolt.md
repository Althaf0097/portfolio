## 2025-08-07 - GPU-Accelerated Spotlight Glare & R3F Memory Optimization
**Learning:** Real-time mouse-tracking elements (such as `InteractiveCard.jsx`) suffer from extreme rendering overhead when continuously updating raw background radial-gradients via GSAP. This is because background-image changes force costly CPU repaints and style recalculation. A far more performant approach is to create a static overlay element containing the gradient and translate it using GPU-hardware-accelerated `translate3d` (via GSAP `quickTo`). Additionally, React Three Fiber (R3F) texture generation can cause memory leaks and GC overhead unless canvas texture instantiation is properly memoized using `useMemo` and cleanly disposed during unmount.
**Action:** Always refactor high-frequency mouse styling to use static overlays positioned with `will-change: transform` and translated via `gsap.quickTo`. Memoize dynamic textures and implement cleanup hooks calling `.dispose()` on WebGL components.
