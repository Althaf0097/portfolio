## 2025-05-20 - InteractiveCard Layout Thrashing & GSAP quickTo GPU Acceleration
**Learning:** High-frequency mouse event handlers calling `getBoundingClientRect()` on every `mousemove` frame trigger synchronous layout thrashing and main-thread recalculations. Additionally, animating gradient `background` properties or creating new `gsap.to()` tween instances per mouse movement creates severe GC overhead and frame drops during fast pointer movements.
**Action:** Cache page-relative element bounding rectangles (`rect.top + window.scrollY`, `rect.left + window.scrollX`) on `mouseenter`, pre-initialize GSAP `quickTo` animation setters for 3D tilt (`rotateX`, `rotateY`, `y`, `scale`) and glare positioning inside `useEffect`, and shift glare movement to a dedicated absolute-positioned element using `transform: translate3d()` for hardware acceleration.
