## 2025-05-18 - Caching Element Bounds & GSAP quickTo Setters for High-Frequency Mouse Events
**Learning:** Calling `getBoundingClientRect()` on every `mousemove` event causes synchronous layout recalculation (layout thrashing) that stalls the browser main thread at 60-120Hz. Furthermore, instantiating new GSAP tweens and assigning string-interpolated CSS `background: radial-gradient(...)` properties on every frame triggers continuous style recalculations and repaints.
**Action:** Cache element bounds (`rect` + scroll offset) in a `useRef` initialized during `onMouseEnter`. Initialize GSAP `quickTo` setters once inside `useEffect` and translate a hardware-accelerated absolute glare overlay with `translate3d(x, y, 0)` to offload animation rendering entirely to the GPU compositor thread.
