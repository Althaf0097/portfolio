## 2024-05-23 - GPU-Accelerated Particles & Ref-based Interaction
**Learning:** High-frequency state updates (mouse/scroll) in React 19 trigger significant reconciliation overhead even if components are memoized. Offloading these to `useRef` and updating Three.js `ShaderMaterial` uniforms directly bypasses React entirely for the render loop, reducing re-renders by over 95%. Additionally, CPU-based position array updates are O(n) and bottleneck the main thread; vertex shaders handle this at O(1) CPU cost.
**Action:** Use `useRef` for all high-frequency interaction data in 3D scenes. Implement `ShaderMaterial` for any particle system exceeding 300 units to ensure 60fps on mobile and low-end devices. Move non-deterministic data generation outside component scope to maintain React 19 hook purity.
