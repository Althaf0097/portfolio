## 2024-08-11 - GPU-Accelerated Spotlight Glare and Non-Blocking Card Dimension Caching
**Learning:** Modifying CSS properties like `background` dynamically during high-frequency mouse-move events (e.g., in `InteractiveCard.jsx`) forces the browser's main thread to run expensive paint and layout recalculations on every frame, resulting in dropped frames and visual lag. By decoupling the glare from the background and shifting it to an absolute-positioned overlay moved via `transform: translate3d()` and GSAP `quickTo`, we can fully delegate style updates to the GPU. Furthermore, calling `.getBoundingClientRect()` inside the `onMouseMove` event causes severe layout thrashing; caching dimensions on `onMouseEnter` and correcting for page scroll completely avoids main-thread blocks.
**Action:** Always avoid dynamic background/gradient updates on mouse moves; instead, move a fixed-background element via transforms and pre-initialized `gsap.quickTo` helpers. Always cache element bounds on low-frequency events like `onMouseEnter` rather than inside high-frequency `onMouseMove`.
