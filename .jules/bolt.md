## 2026-07-20 - High-Frequency Mouse-Tracking in Interactive 3D Cards
**Learning:** Calling `getBoundingClientRect()` on every `mousemove` event in `InteractiveCard` caused synchronous layout recalculation and layout thrashing. Creating new `gsap.to` tweens on every mousemove event and recalculating radial-gradient backgrounds on the main thread added high CPU overhead and stutter, aggravated by `transition-all` CSS rules fighting GSAP's transform updates.
**Action:** In high-frequency interaction components like `InteractiveCard`, cache element layout dimensions and scroll offsets in a `useRef` on `onMouseEnter`, use pre-initialized `gsap.quickTo` pipelines for 3D tilt and translate, animate spotlight glares using GPU-accelerated overlay transforms (`translate3d`), and restrict CSS transitions away from properties actively animated by GSAP.
