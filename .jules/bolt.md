## 2025-05-18 - High-Frequency Reflow Elimination & WebGL Texture Memoization
**Learning:** High-frequency mouse tracking interactions inside `onMouseMove` cause severe layout thrashing and paint bottlenecks if element dimensions (`getBoundingClientRect`) are queried on every single cursor move event. Shifting absolute-positioned effects to GPU-accelerated 3D transforms (`translate3d`) using GSAP's optimized `quickTo` utility instead of inline background property modifications drastically improves main-thread performance. Furthermore, recreating Canvas elements and ThreeJS `CanvasTexture`s on every render loop causes massive memory leaks and WebGL garbage collection thrashing in `@react-three/fiber` scenes.
**Action:** Always cache container bounding boxes on mouse enter/scroll inside a `useRef` to completely bypass querying the DOM layout during active move tracking. Use absolute-positioned overlay nodes for hover/glare effects, and memoize custom-generated `CanvasTexture` arrays inside ThreeJS components using `useMemo` to safeguard WebGL performance.
