## 2025-05-18 - Hardware-Accelerated Glare and Cached Bounding Rects in High-Frequency Interactive Cards
**Learning:** Calling `getBoundingClientRect()` on every `onMouseMove` frame in interactive 3D cards triggers forced synchronous layout reflows (layout thrashing). Furthermore, updating `background` radial-gradient strings dynamically on every frame forces main-thread string parsing, style recalculation, and repaints. Pre-allocating GSAP `quickTo` setters inside `useEffect`, caching bounding box dimensions during `onMouseEnter`, and animating an absolute radial glare overlay via `transform: translate3d()` completely shifts rendering to GPU composition layers.
**Action:** Always pre-allocate `gsap.quickTo` setters once inside `useEffect`, cache container dimensions during `onMouseEnter`, and use GPU transforms (`translate3d`) for mouse-following glare/spotlight effects.
