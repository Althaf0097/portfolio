## 2025-05-18 - Pre-initialized GSAP quickTo and Bounding Rect Caching for 3D Tilt Cards
**Learning:** Calling `getBoundingClientRect()` on high-frequency `mousemove` events causes layout thrashing (forced reflow) on every cursor movement, while setting CSS radial-gradient background strings forces main-thread repaints. Pre-initializing GSAP `quickTo` setters once inside `useEffect` and caching card bounding dimensions on `mouseenter` eliminates layout thrashing and reduces frame interaction time to near 0ms.
**Action:** When implementing high-frequency 3D tilt or cursor tracking interactions, pre-instantiate `gsap.quickTo` setters inside `useEffect`, cache container dimensions on entry, and use `transform: translate3d()` for glare overlays to move rendering workload entirely to the GPU.
