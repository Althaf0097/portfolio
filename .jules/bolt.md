## 2023-11-20 - High-Performance Mouse-Tracking in Interactive Components
**Learning:** High-frequency mouse interaction effects like cursor spotlight glow or card glare are prone to massive layout thrashing and paint storm bottlenecks. Reading `getBoundingClientRect()` inside an `onMouseMove` event causes the browser to synchronously recalculate layout on every pixel moved. Updating standard radial gradient CSS backgrounds triggers heavy main-thread repaints.
**Action:** Always cache container dimensions inside a `useRef` initialized during `onMouseEnter` to completely eliminate layout thrashing. Implement glow/glare animations using a dedicated, absolute-positioned GPU layer moved with `transform: translate3d()` and GSAP's optimized `gsap.quickTo()` to shift workloads to the compositor thread.
