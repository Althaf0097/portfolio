## 2025-05-18 - Hardware-Accelerated Glare Overlay for Interactive Cards
**Learning:** Updating inline CSS `background` radial-gradient strings in high-frequency `mousemove` handlers causes main-thread style recalculation and painting bottlenecks. Replacing inline dynamic background strings with an absolute-positioned glare overlay element moved via GSAP `quickTo()` hardware-accelerated `transform: translate3d()` and `opacity` shifts animation processing to GPU composite layers and completely prevents layout thrashing.
**Action:** When creating interactive 3D cards or spotlight effects, avoid inline gradient string construction in `onMouseMove`; instead, use a fixed overlay div updated via GSAP `quickTo` transform/opacity setters and cache `getBoundingClientRect()` on `mouseenter`.
